Physical model, SI units and boundary assumptions

Air-only rectangular closed sheet: x/y from0.4to0.6m, z from0.4to0.6m, N=1turn, I=1A. No core or finite solved copper. Linear reference edge-element equations curl(nu curl A)=J, B=curl A; outer tangential A=0. Domains1m and2m cubed, with rigidly translated identical source/probes. The independent free-space reference integrates B=mu0/(4pi) integral(I dl cross r/|r|³), averaged uniformly over sheet height. B[T], dl/r[m], I[A], mu0[H/m]. This compares different exterior boundaries: discrepancy combines discretization and boundary effects and is not a certified isolated FEM-error bound.

Algorithm and actual checks

Four directed sides include the complete return. Independent midpoint quadrature uses64and128subdivisions both along each side and along sheet height; centre is separately checked against the rectangular-loop axial expression integrated with2000midpoints. Both checks require less than0.1% relative difference and passed. Observed maximum quadrature change is0.004758%; this is empirical stability, not a rigorous bound. Four real FEM solves use base target4at air1 and8at air2, with every fitted interval factor1or2. Their cell counts are750,6000,4374,34992. The last case exceeds the GUI port-study24000cell ceiling: it is a direct numerical verification using the original standard3D mesh budget, not evidence that the GUI accepts it. Fields are averaged over all incident containing tetrahedra using barycentric coordinates. Three fixed source-relative probes include centre and an inversion-symmetric off-axis pair.
