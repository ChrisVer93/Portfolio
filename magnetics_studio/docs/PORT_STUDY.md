# Reference multiwinding mesh / air study — S003

Solve a linear rectangular 2D/3D model with Matrix enabled. In Inductance, select the driven electrical ID and the other windings to short. Enter increasing integer Mesh factors and Air factors, each starting at1, then Run mesh / air study. The default `1,2` / `1` varies mesh at fixed outer boundary. `1` / `1,2` varies exterior size at the same nominal physical mesh spacing. A crossed grid, such as `1,2,3` / `1,2`, tests both effects together. The source CLI is `python tools/study_ports.py source.json study.json --input-id primary --short secondary --mesh-factors 1,2,3 --air-factors 1,2`; use actual canonical IDs from the electrical matrix.

Every point freshly solves the original reference field and all physical unit excitations. Canonical same-current grouping defines electrical ports; equal display names remain independent. The preceding S002 reduction enforces all selected shorted-port incremental linkages to zero, with every unselected winding current zero/open. This is a linear lossless ideal-short measurement, not a resistive AC load, a nonlinear tangent or a unique magnetising/leakage T-network split. Native Netgen controls do not apply to this study. Original accepted fields and the source project remain intact.

For mesh factor h and air factor a, outer width/height (and 3D depth) multiply by a; nx/ny/(nz) multiply by h*a. Every physical region and 3D sheet window translates by half the added exterior size. Physical geometry, feature separations, material laws, turns, polarities, electrical IDs and section order are retained. Planar extrusion depth stays fixed. Detached builder cases are flagged as edited; the original recipe is not silently rebuilt. Integer factors avoid target-rounding coarsening during air-only comparisons. Interior subdivisions between physical geometry planes remain unchanged at fixed h, but exterior-air topology changes. Domain sensitivity therefore includes exterior discretization differences; it is not an isolated, certified boundary-error estimate.

Original formulations remain -div(nu grad Az)=Jz for planar P1 triangles and curl(nu curl A)=J for spatial edge elements; B=curl A, W=integral(B dot H)/2. nu[m/H], A[Wb/m], B[T], J[A/m²], W[J], L[H], lambda[Wb turn]. Az=0 planar and tangential-A=0 spatial exterior boundaries remain closed. 2D paired source Jz=±NI/area uses original stack depth; 3D sources remain ideal closed rectangular sheets. No finite solved copper, native nonlinear/AC, new mesh kernel or certified estimator is added.

Each point retains its exact generated project, project/actual-mesh SHA256, fitted cell count, full electrical matrix, selected cancellation currents/linkages and original-current solver diagnostics. Selected1A energy is matrix-derived; original-current stats must not be interpreted as the shorted field. Relative changes use abs(Lnew-Lold)/max(abs(Lnew),abs(Lold),1e-30) along one axis while holding the other factor fixed. First comparisons are null. Identical adjacent actual fitted meshes are flagged and excluded from mesh-change evidence; increasing a requested subdivision number does not guarantee a changed fitted mesh. No automatic pass/converged label is issued.

At most6cases, factors1..3,24000actual fitted cells/case and240000cell-excitations total are accepted; work accounts for the original-current field plus every physical-source matrix column. Every case is preflighted before replacing accepted job state. Unsupported B-H, polygon or declared/assigned AC-solid inputs are rejected. Original cancellation propagates between/during numerical cases; an incomplete study is not published. Browser worker termination retains prior accepted field/export data. Lower base subdivisions or reduce factors if the resource preflight rejects a large original model.
