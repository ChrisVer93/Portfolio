# Linear open / simultaneous short measurements — S002

Solve a linear 2D or 3D model with **Matrix** enabled. In **Inductance**, select the driven electrical winding and tick every winding to short. Unticked windings stay open (zero current). Calculate and save the measurement JSON, which includes the exact supplied electrical matrix, its SHA256, selected stable IDs, all cancellation currents and linkages, the accepted source project and solver metadata. `three_winding_2d` is a reproducible example. Equal display names do not connect sources; original canonical series membership defines the electrical matrix.

This is lossless linear matrix postprocessing. It does not start a field job or overwrite the accepted field/project. Re-solve with the exported currents for a field plot of the shorted condition. Nonlinear/AC results without a real static matrix have no control. Singular/nearly dependent ideal ports are rejected; there is no guessed pseudoinverse or resistance regularization.

For a reciprocal positive definite matrix in henries, lambda = L i (Wb turn), W = i^T L i / 2 (J). Let p be the driven port, S the shorted set and all other currents zero. Setting i_p = 1 A and lambda_S = 0 gives i_S = -L_SS^{-1} L_Sp A and L_input = L_pp - L_pS L_SS^{-1} L_Sp. This accounts for mutual coupling between all shorted windings, unlike separate pairwise short measurements. Shorted currents can have either sign. For nonzero-frequency sinusoidal excitation, these conditions correspond to ideal zero-resistance shorts and zero incremental/trapped flux; they are not a resistive AC or transient solution.

The implementation scales by sqrt(L_ii), checks normalized reciprocity (<=1e-6), explicitly symmetrizes that qualified numerical discrepancy, and uses Cholesky factors plus triangular substitutions. Every normalized energy pivot must exceed 1e-10. This is an independence guard, not a condition-number or physical-error bound. Full-matrix positivity is required. Energy and shorted-linkage residuals must be <=1e-8 in the documented normalization. The exact original unsymmetrized input matrix and discrepancy remain in the export.

Open-input L_pp is self inductance. The difference between open and shorted input inductance is cancelled coupling; neither value defines a unique magnetising/leakage T-network decomposition. No turns-ratio assumption, core-only flux partition or arbitrary Lm label is introduced. These values are not interchangeable with the OpenMagnetics adviser's model-specific Lm/leakage definitions without a matched model and equivalent-circuit convention.

Actual reference tests re-solve the prescribed cancellation currents on independent 2D H1 and 3D edge-element fields. The 338-triangle planar model gives open1216.731151958µH / both-short119.418354605µH. The 2940-tetrahedron spatial ideal-sheet model gives open168.095713276µH / both-short131.482603490µH. Their field-energy prediction differences are8.71e-12 /4.55e-11 relative. These are same-model algebra/field consistency checks on coarse meshes, not mesh/domain convergence, finite-copper validation or Maxwell/hardware evidence. Original material/source/boundary equations are unchanged: closed Az=0 planar boundary with depth scaling; tangential-A=0 spatial boundary and ideal closed sheet sources.
