Engineering workflow

MAGNETICS STUDIO 0.8 · INDEPENDENT IMPLEMENTATION

Guided builder

Click Builder and follow Core type → Dimensions → Material → Air gaps → Circuits → Windings → Interleaving → Nameplate/build. The same circuit and winding inputs drive 2D and 3D geometry.

Circuits and independent windings

A named circuit, such as Phase U, contains its own winding count and winding definitions. Primary and secondary have independent turns, current and phase. Only physical layers of one electrical winding carry the same series current. Reorder those layers per limb to define interleaving. Single, multilayer and interleaved arrangements are supported. Declared totals and odd final layers are checked.

Signed instantaneous current is the default excitation. Optional sinusoidal snapshot mode uses peak current × cos(snapshot angle + winding phase). It is a prescribed magnetostatic point, not a voltage-driven or AC circuit solve. Phase names do not impose phase angles.

Material and image digitiser

Select a material, enter linear μr, import numeric B–H data, or click Digitise from graph image in Material. Load a screenshot, enter graph limits/units/scales and calibrate A=(Xmin,Ymin), B=(Xmax,Ymin), C=(Xmin,Ymax). Trace one monotonic positive branch. Scroll zooms; Shift/right-drag pans. Move/delete points or edit their SI values. Invalid points block application; including (0,0) is an explicit assumption. Images stay in the local browser. Perspective photographs are not corrected.

Nonlinear reversible B–H is available in 2D. 3D remains linear; storing a curve in 3D does not activate nonlinear physics. Temperature/frequency labels select curve data explicitly; no automatic scaling or loss model is implied.

2D and 3D windings

2D supports full winding-block rectangles or separately meshed round/litz/foil/rectangular turn sections. A region carrying n turns has Jz = ±nI/A. Each winding has both + and − sections, preserving total ampere-turns. Round curves are faceted polygons. Litz is homogenized within each bundle, not resolved strand by strand. Stack depth scales linkage and energy; planar end effects are absent.

3D uses closed ideal rectangular current sheets at the packing-defined mean radius and axial extent. It computes 3D field end effects in a finite air domain. Winding display envelopes do not represent finite-copper eddy-current physics. Curved toroidal 3D cores and individual 3D wires are not implemented.

Mesh, solve and inspect

Preview and check fit, then use the model in the workspace, generate mesh and solve. Standard 3D budget is 44k tetrahedra; the explicitly selected extended budget allows 120k and may be slower. The builder shows a mesh estimate. Uncheck Matrix for field-only analysis. Failed convergence is rejected.

Use 3D field volume for magnitude colours, volume arrows, traced B paths, transparency and capped core surfaces. Rotating field slice remains a single plane. Streamlines are approximate postprocessing of elementwise fields. The solid model view provides part selection, hiding, cutaway and display OBJ export.

Results and verification

Linear inductance uses independent unit excitations. Native 3D section matrices are grouped by electrical winding, not by circuit container. Per-container winding-pair leakage assumes the selected other winding is shorted and all remaining winding currents are zero/open; the full coupled matrix is retained. Nonlinear points do not have a constant linear inductance matrix.

Check finer mesh and larger air boundaries. A tiny algebraic residual or energy discrepancy alone is not evidence of engineering accuracy. The closed outer boundary imposes zero normal flux and is not an infinite open boundary. Sharp-corner field peaks can remain mesh dependent.

Save and reuse

Save project JSON for the workspace, builder input JSON for the recipe, or a digitiser session including the source graph image. Changing raw generated geometry flags the recipe as stale; rebuilding does not infer manual edits. Previous v0.5 recipes migrate with their explicit geometry preserved. CSV, JSON, VTK, PNG and self-contained HTML reports remain available.

Release boundaries

Independent research software with limited validation. Linear 2D AC/eddy-current analysis is available with explicit solid-conductor current constraints and RMS phasors. No 3D/nonlinear AC, transient, core-loss, hysteresis, thermal, permanent-magnet, force/torque, arbitrary CAD or general 3D adaptive-meshing solver is added. Linear 2D local residual-driven refinement is available from Analysis; its indicator is not a certified error bound. The circuit hierarchy is a modelling definition, not a general electrical network solver.
